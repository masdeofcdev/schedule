# 🏆 Workout Schedule App

Calisthenics + Dumbbell weekly workout schedule — built with React + Vite.

## Deploy ke Vercel (3 langkah)

### Cara 1: Via GitHub (Recommended)
1. Upload folder ini ke GitHub repo baru
2. Buka [vercel.com](https://vercel.com) → Login → **Add New Project**
3. Import repo GitHub kamu → klik **Deploy** → selesai! ✅

### Cara 2: Via Vercel CLI
```bash
npm install -g vercel
cd workout-app
vercel
```

## Run Lokal
```bash
npm install
npm run dev
```
Buka http://localhost:5173
